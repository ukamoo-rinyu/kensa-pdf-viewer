# kensa-pdf-viewer

しおり(ブックマーク)付きの結合PDFを検査するためのビューアーです。PDF上に指摘を記録して一覧をExcelに書き出し、再提出された新版と旧版を並べて、どこが変わったかを確認できます。

工事関係書類のように、多数の資料をしおりで整理して1本のPDFにまとめた提出物(たとえば KojiPDF で作ったもの)を想定しています。Windows で開発・確認しています。

> **試作段階です。** 差分の表示は「見るべき場所の当たりをつける補助」です。検査の根拠にはせず、必ず人が旧版と新版を並べて確認してください。差分が出ないページも「修正されていない」とは限りません。

## できること

### 指摘の記録と一覧
- PDF上をクリックして、指摘のピン(付箋)を置く。区分(要修正/要確認/軽微/質問)・状態(未対応/修正済/確認済/再指摘)・内容・指摘者・検査回次を記録
- しおりの区間全体に対する、位置を指定しない指摘
- 指摘一覧(区分・状態で絞り込み、クリックで該当ページへ移動)
- 指摘一覧を Excel(.xlsx)に書き出し
- 指摘は JSON ファイル1本で保存。複数の検査員の指摘ファイルを取り込んで統合できる(同じファイルを何度取り込んでも重複しない)

### 新旧の比較
- 旧版と新版を左右に並べて表示。指摘一覧の行をクリックすると、旧版は指摘の位置、新版は対応するページを同時に開く
- しおり構成の差分(追加された章・削除された章・名前が変わった章)
- **差分の表示**: 変わった文字(1文字単位)と、図・写真の変化を色付きの枠で重ねて表示
  - 赤: 旧版で消えた・変わった文字 / 緑: 新版で増えた・変わった文字 / 紫: 図・画像の変化
  - 文字のページがスキャン画像に置き換わった場合も知らせる
- 「前の差分/次の差分」で、変更のあったページだけを順に送る
- 「ページ送りを連動」で、片側をめくるともう片側も対応するページへ移る

### ページ番号に頼らない設計
指摘の位置も、旧版と新版のページの対応も、**ページ番号ではなく「しおりの位置+その中の何ページ目か」**で持ちます。差し替えでページが増減しても、指摘がずれた場所を指しません。

- しおり名の末尾に付くページ番号(例: `京都駅周辺_77_1`)は、比較のときには取り除いて扱います
- 章の途中にページが挿入・削除された場合は、ページの内容の類似度で対応を取ります
- 対応が特定できないときは「照合できず」と表示し、推測で別の場所を開きません

## 必要なもの

- Python 3.10 以降
- 依存ライブラリ: PySide6, PyMuPDF, openpyxl(`requirements.txt`)

## インストールと起動

```bash
git clone https://github.com/ukamoo-rinyu/kensa-pdf-viewer.git
cd kensa-pdf-viewer
python -m pip install -r requirements.txt
python main_kensa.py
```

開くPDFを引数で渡すこともできます。

```bash
python main_kensa.py "C:/path/to/資料.pdf"
```

## 使い方

1. ツールバーの「PDFを開く…」で旧版(初回提出版)のPDFを開く
2. 「📍 マーカーを置いて指摘を追加」をONにしてPDF上をクリックし、指摘を記録する(ダブルクリックでも追加できる)。
   ページの特定の位置ではなく章全体への指摘は、左のしおりを選んで「選択中のしおり全体に指摘を追加」を押す
3. 「指摘ファイルを保存…」で指摘を JSON に保存する。「Excelに書き出し…」で一覧表を作る
4. 再提出版が届いたら、旧版と指摘ファイルを開いた状態で「新旧2画面で比較…」を押し、新版のPDFを選ぶ
5. 比較画面の「次の差分 ▶」で変更箇所を順に確認する。左の指摘一覧から、指摘ごとの修正状況を確認する

## 対象外・制約

- しおりが付いていないPDFは、しおりによる照合ができません(比較画面ではページ順での対応になります)
- KojiPDF の「メール束PDF」形式は対象外です(メール束は [mail-pdf-viewer](https://github.com/ukamoo-rinyu/mail-pdf-viewer) で閲覧できます)
- 差分の検出は資料の種類で精度が変わります
  - Word/Excel などから出力した文書: 文字単位で精度よく検出
  - CADなどの図面: 図形の変化は画像の比較で検出(図の中の文字の部分は文字の比較に任せる)
  - スキャンした資料: スキャンし直すと傾き・ずれ・濃度が変わるため、誤検出が出ることがあります。位置合わせの補正は未実装です
- 白黒にして比べているため、色だけが変わった場合は検出しません
- 大きなPDF(数百ページ)では「次の差分」の検索に時間がかかることがあります(進捗表示と中止あり)

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `main_kensa.py` | 起動 |
| `kensa_window.py` | メイン画面(PDF表示・指摘の記録・一覧) |
| `compare_window.py` | 新旧比較画面 |
| `indications.py` | 指摘データとJSON保存・統合 |
| `matching.py` | 新版PDFへの指摘の照合 |
| `bookmark_diff.py` | しおり構成の差分 |
| `page_diff.py` | 旧新ページの対応付けと、ページ単位の差分 |
| `pdf_sections.py` | しおり階層の読み取り |
| `export_excel.py` | Excel書き出し |
| `devtools/` | 差分検出の評価・動作確認用のスクリプト |
| `docs/` | [開発メモ](docs/開発メモ.md)(実装の記録・評価結果・既知の課題) |
